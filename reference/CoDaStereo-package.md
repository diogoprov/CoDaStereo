# CoDaStereo: Compositional Data Analysis for Stereological and Histomorphometric Data

Interactive 'shiny' application for compositional data analysis of
stereological, histomorphometric and blood-cell count data under the
Aitchison geometry. It covers data upload and inspection, zero and
missing-value replacement, ternary diagrams, centred log-ratio biplots,
user-editable sequential binary partitions with CoDa dendrograms, and
permutational multivariate analysis of variance on isometric log-ratio
coordinates, optionally including the log-transformed total as described
by Pawlowsky-Glahn, Egozcue and Lovell (2015)
[doi:10.1177/1471082X14535526](https://doi.org/10.1177/1471082X14535526)
.
